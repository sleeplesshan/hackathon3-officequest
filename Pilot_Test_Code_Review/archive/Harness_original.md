# 🛡️ [AGENT HARNESS] 오피스퀘스트 (Office Quest) & 효성마을 Autopilot 실행 규약

이 문서는 자율 주행(Autopilot) 에이전트가 **오피스퀘스트 & 효성마을** 플랫폼을 사람의 개입 없이 완벽한 코드 퀄리티로 완주하기 위한 **최상위 실행 제어 하네스(Execution Harness)**입니다. 에이전트는 모든 코드 생성, 상태 관리, UI 렌더링, 테스트 과정에서 본 문서의 규칙을 절대적으로 준수해야 합니다.

---

## 1. 기술 스택 및 아키텍처 제약 (Tech Stack Constraints)

에이전트는 임의로 기술 스택을 변경하거나 기능을 축소할 수 없으며, 아래 정의된 스펙을 100% 충족해야 합니다.

| 영역 | 기술 스택 및 구현 강제 사항 |
| :--- | :--- |
| **Core Framework** | **Next.js (App Router)** + **TypeScript (`strict: true`)** + **Tailwind CSS** + **Lucide React** |
| **Real-time Mock DB** | 백엔드 서버 없이 동작하되, **React Context + `localStorage` + `BroadcastChannel` (또는 `window.dispatchEvent`)**를 결합하여 페르소나 전환, 포인트 증감, 게시글 상태 변경이 새로고침 없이 모든 컴포넌트에 **실시간(Real-time)**으로 즉시 반영되어야 함. |
| **Rich Text Editor** | 효성 표준 **TinyMCE 5.10.2** 스펙 준수. 클라우드 API Key 경고창("This domain is not registered...")이 절대 뜨지 않도록 Self-hosted 스크립트 방식 또는 API Key Free 커스텀 리치 에디터 폴백(표, 색상, 정렬, 리스트, 스크린샷/이미지 첨부 툴바 필수 포함)으로 완벽 구현할 것. |
| **2D Pixel & Motion** | 외부 깨진 이미지 URL 사용 절대 금지. **HTML5 `<canvas>` 2D 픽셀 배열 렌더러** 및 **CSS `@keyframes`**를 직접 코드로 작성하여 6단계 티어별 도트 캐릭터와 1.8초 하이퍼 프레임 모션 오버레이를 100% 자체 렌더링할 것. |
| **Typography** | **페이퍼로지 (`Paperlogy`)** 웹폰트 CDN을 `globals.css`에 `@font-face`로 선언하고 `font-sans` 기본값으로 지정하여 모든 타이틀, 본문, 숫자에 일괄 적용할 것. |

## 2. 인라인 스킬 명세 (Embedded Skills Specification)

에이전트는 코드 작성 시 다음 4가지 스킬 모듈을 상시 활성화하여 결과물에 투영합니다.

### 🎨 Skill 1: `taste` (Anti-AI-Slop & Refined Purple Design)
* **금지 사항 (No AI-Slop):** 원색적인 무지개 그라데이션, 촌스러운 기본 그림자, 정렬이 어긋난 카드 높이, 의미 없는 빈 껍데기 버튼(`onClick={() => {}}`), 시스템 기본 폰트 노출을 엄격히 금지합니다.
* **컬러 토큰:**
  * **Light Mode (기본):** 배경 `#FAFAFC`, 카드 `#FFFFFF`, 기본 텍스트 `#18181B`, 시그니처 보라 `#6D28D9` / `#7C3AED`, 소프트 배지 `#EDE9FE`, 보더 `#E4E4E7`.
  * **Dark Mode (사이버펑크/게이밍 무드):** 배경 `#09090B`, 카드 `#12121A`, 네온 퍼플 `#A855F7`, 사이버 시안 포인트 `#06B6D4`, 보더 `#27272A`.

### 🍱 Skill 2: `mengto` (Bento Grid & High-Craft Dashboard)
* 로그인 직후 노출되는 메인 대시보드는 **비대칭 벤토 그리드(Bento Grid)** 레이아웃으로 설계합니다.
* **필수 그리드 셀 구성:**
  1. **[Hero Cell]** 내 2D 도트 캐릭터(티어 오라 포함) + 레벨/EXP 프로그레스 바 + 보유 포인트 + 오늘 완료 건수(0/2).
  2. **[Ranking Cell]** 2026 Season 1 종료 D-Day 카운터 + 실시간 TOP 5 랭킹 보드 + `[시즌 초기화 시뮬레이션]` 버튼.
  3. **[Daily Quest Cell]** 오늘의 일일 퀘스트 4종 달성률 및 즉시 보상(`+10P`) 수령 위젯.
  4. **[Live Feed Cell]** 방금 올라온 업무 퀘스트 & 효성마을 인기 매물 요약 프리뷰.

### 👾 Skill 3: `Sprite-gen` (Pixel Art & Hyper-Frame Engine)
* **티어별 도트 캐릭터 진화:** `브론즈` → `실버` → `골드` → `플래티넘` → `다이아` → `마스터` 6단계에 따라 캐릭터의 장비(망토, 갑옷, 사이버 고글, 날개, 전설의 검)와 배경 픽셀 파티클 오라가 실시간으로 다르게 렌더링되어야 합니다.
* **하이퍼 프레임(Hyper-Frame) 전체화면 오버레이 모달:**
  * **트리거 1 (퀘스트 등록 시):** 캐릭터가 양피지 퀘스트 보드를 꽂으며 보랏빛 광채가 퍼지는 도트 애니메이션.
  * **트리거 2 (퀘스트 완료 승인 시):** 캐릭터가 '업무 병목 몬스터'를 보랏빛 검기로 베어 처치하고 골드 코인(+100P + 현상금)이 쏟아지는 도트 애니메이션.
  * **스펙:** 화면 정중앙 전체 오버레이(`fixed inset-0 z-[9999] bg-black/75 backdrop-blur-sm`)로 **정확히 1.8초간 재생 후 자동 종료**됩니다.

### 🧠 Skill 4: `sleeplesshan/dual-brain` (좌우뇌 교차 검수 프로토콜)
* 각 개발 Phase가 끝날 때마다 에이전트는 작업을 잠시 멈추고 아래 두 가지 페르소나로 코드를 교차 검증합니다.
  * **Left Brain (좌뇌 - 논리/데이터/제약조건 감리):** 포인트 선차감(에스크로) 및 환불 수식, 일 2건 완료 한도, 2시간 타이머 소진 시 버튼 비활성화(효성마을은 예외), 문의/요청 파일 첨부 분기, 예약중 상태 시 지정 구매자 외 구매 차단, TypeScript 타입 무결성을 검증합니다.
  * **Right Brain (우뇌 - UX/심미성/모션 감리):** 페이퍼로지 폰트 적용 여부, 라이트/다크 모드 대비, 도트 애니메이션 프레임 드랍 여부, 빈 화면/깨진 UI 유무를 검증합니다.
