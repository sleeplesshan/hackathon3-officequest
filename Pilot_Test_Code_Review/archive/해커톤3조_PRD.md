# 🚀 [AUTOPILOT MASTER PROMPT & PRD] 오피스퀘스트 (Office Quest) & 효성마을

당신은 자율 주행(Autopilot) 풀스택 엔지니어링 오케스트레이터입니다. 
사용자의 추가 개입 없이 아래에 정의된 **PRD(제품 요구사항 정의서), 인라인 스킬(Skills), Subagent 파이프라인, 그리고 최종 완료 조건(Definition of Done)**이 100% 달성될 때까지 스스로 코드를 작성, 검수, 수정, 빌드 및 테스트를 반복 수행하십시오. **Goal을 완벽히 달성했을 때만 작업을 종료합니다.**

## 🧠 1. 인라인 스킬 및 하네스 정의 (Inline Skills & Harness Rules)

작업 전 과정에 걸쳐 아래 4가지 스킬의 규칙을 엄격히 준수하여 코드에 반영하십시오.

### Skill A: `taste` (Anti-AI-Slop & High-Craft Design)
- **목적:** 흔한 AI 생성물 특유의 촌스러운 디자인(무분별한 네온 그라데이션, 어색한 여백, 기본 시스템 폰트, 뻔한 레이아웃)을 철저히 배제합니다.
- **규칙:**
  1. **Typography:** 전체 웹폰트로 **'페이퍼로지(Paperlogy)'** CDN(`https://fastly.jsdelivr.net/gh/projectnoonnu/2408-3@1.0/Paperlogy-4Regular.woff2` 및 6SemiBold, 8ExtraBold 등 `@font-face` 선언)을 로드하여 모든 UI와 숫자에 일괄 적용합니다.
  2. **Color System:** 세련된 보랏빛(Refined Royal/Electric Purple)을 시그니처로 사용합니다.
     - **기본 테마 (Light Mode):** `#FAFAFC` 배경, `#FFFFFF` 서피스, `#18181B` 텍스트, `#6D28D9`(Deep Purple) 및 `#7C3AED`(Vibrant Violet) 포인트, `#EDE9FE` 소프트 배지, 미세한 보더(`1px solid #E4E4E7`).
     - **다크 모드 (Cyberpunk/Gaming Mode 토글 지원):** `#09090B` 배경, `#12121A` 카드 서피스, `#A855F7` 네온 퍼플 액센트, `#27272A` 보더.
  3. **Micro-interactions:** 모든 버튼과 메뉴 이동, 마우스 오버 시 부드러운 트랜지션과 픽셀 아이콘/배지 반응을 제공합니다.

### Skill B: `mengto` (Bento Grid & High-Converting Dashboard UI)
- **목적:** 로그인 직후 보이는 메인 대시보드를 Apple/Linear 스타일의 세련된 **벤토 그리드(Bento Grid)** 레이아웃과 깊이감 있는 카드 UI로 구축합니다.
- **규칙:**
  1. 대시보드 상단에는 [내 2D 도트 캐릭터 스테이터스 카드], [시즌 D-Day 및 TOP 5 랭킹 보드], [오늘의 일일 퀘스트 진행률], [최신 업무 퀘스트 & 효성마을 인기 매물 요약]을 비대칭 벤토 그리드로 배치합니다.
  2. 카드 내부에는 미묘한 글래스모피즘(Glassmorphism), 정교한 패딩(20px~24px), 명확한 시각적 위계(Visual Hierarchy)를 적용합니다.

### Skill C: `Sprite-gen` (2D Pixel Art & Hyper-Frame Motion Graphics)
- **목적:** 게이미피케이션 요소를 극대화하기 위해 HTML5 `<canvas>` 및 CSS `@keyframes` 기반의 순수 코드형 픽셀 아트 스프라이트 엔진을 구현합니다. (외부 깨진 이미지 링크에 의존하지 않고, 16x16 / 32x32 픽셀 매트릭스 배열 렌더러를 코드로 직접 구현하여 100% 렌더링 보장)
- **규칙:**
  1. **티어별 캐릭터 외형 진화:** 브론즈(기본 사원복) → 실버(은빛 망토) → 골드(황금 갑옷) → 플래티넘(사이버 고글+오라) → 다이아(크리스탈 날개) → 마스터(보랏빛 번개 아우라+전설의 검) 6단계에 따라 대시보드의 도트 캐릭터 스프라이트와 주변 파티클 오라(Aura)가 실시간으로 화려하게 변화합니다.
  2. **하이퍼 프레임(Hyper-Frame) 전체 화면 오버레이 모달:**
     - **퀘스트 등록 시:** 도트 캐릭터가 게시판에 양피지 퀘스트 스크롤을 꽂으며 빛이 퍼지는 모션.
     - **퀘스트 완료 및 포인트 획득 시:** 도트 캐릭터가 '업무 병목 몬스터(슬라임/드래곤)'를 화려한 보랏빛 검기로 베어 처치하고 골드 코인(포인트)과 EXP 보석이 쏟아지는 하이퍼 프레임 애니메이션.
     - **동작 스펙:** 화면 중앙 전체 오버레이 모달(`z-index: 9999`, 반투명 다크 백드롭)로 **1.8초간 임팩트 있게 재생된 후 자동으로 부드럽게 닫힘**.
  3. 메뉴 이동 및 주요 버튼 마우스 오버 시 작은 도트 코인/별 파티클이 튀는 마이크로 모션 적용.

### Skill D: `sleeplesshan/dual-brain` (좌우뇌 교차 검수 하네스)
- **목적:** 주요 마일스톤 단계마다, 그리고 Autopilot 종료 직전에 **좌뇌(Left Brain: 논리/상태/예외처리/빌드 무결성)**와 **우뇌(Right Brain: UX/디자인 완성도/모션/AI-Slop 제거)** 관점으로 자가 비평(Self-Critique) 및 코드 수정을 수행합니다.
- **규칙:** 프로젝트 내 `DUAL_BRAIN_AUDIT.md` 파일을 생성하여 각 단계별 좌/우뇌 검수 결과와 수정 내역을 기록하고, 미비점이 발견되면 즉시 코드를 패치합니다.

## 🤖 2. Subagent 오케스트레이션 파이프라인

복잡도를 제어하고 코드 퀄리티를 극대화하기 위해 다음 5개의 논리적 Subagent 역할을 순차/병렬로 수행하십시오.

1. **`[Subagent 1] Architect & State Agent`**: Next.js(App Router, TypeScript, Tailwind CSS, Lucide Icons) 초기화, 실시간 반응형 Mock DB(React Context + `localStorage` + `BroadcastChannel`/CustomEvent 실시간 동기화) 설계, 경제/시간/티어 수식 엔진 구축.
2. **`[Subagent 2] UI/UX & Mengto/Taste Agent`**: 페이퍼로지 웹폰트 적용, 보랏빛 라이트(기본)/다크 모드 테마 스위치, 상단 GNB(멀티 페르소나 전환기 + 2시간 타이머 + 디버그 컨트롤), 벤토 그리드 메인 대시보드 구축.
3. **`[Subagent 3] Pixel & Motion Agent`**: `Sprite-gen` 캔버스 픽셀 렌더러 컴포넌트 제작, 6단계 티어별 도트 캐릭터 애니메이션, 퀘스트 등록/완료용 1.8초 전체화면 하이퍼 프레임 모달 구현.
4. **`[Subagent 4] Feature Agent (Quest & Hyosung Village & Mock Integrations)`**: TinyMCE 5.10.2 기반 리치 에디터, 보안서약서 모달, 업무 퀘스트(문의/요청, 채택/반려/완료, 쉐어포인트 변환), 효성마을 중고거래(6개 마을, 예약중/지정구매자 제어), 가상 팀즈(Teams) 자동응답 채팅 모달, 그룹웨어 조직도 트리 모달 구현.
5. **`[Subagent 5] Dual-Brain QA & E2E Agent`**: `sleeplesshan/dual-brain` 최종 감리, TypeScript 컴파일 및 `npm run build` 무결성 검증, 핵심 유저 플로우 검증.

## 📐 3. 상세 기능 및 도메인 스펙 (Detailed PRD)

### 3.1 글로벌 헤더 (GNB) 및 시연용 컨트롤 바
- **메인 네비게이션 (2개 상단 메뉴):**
  1. `대시보드` (로고 클릭 시 이동 - 로그인 직후 기본 화면)
  2. `업무 퀘스트` (사내 마이크로 아웃소싱)
  3. `효성마을` (사내 포인트 중고거래)
- **우측 상단 상태 바:**
  - **오늘 남은 작업 가능 시간 타이머:** 기본 `02:00:00` (점심시간 1시간 + 개인 설정/접속 1시간 합산 개념) 실시간 초 단위 카운트다운 표시.
  - **⚡시연용 타이머 컨트롤 아이콘:** 클릭 시 `[시간 00:00:00으로 즉시 소진 (제약 테스트)]` ↔ `[시간 02:00:00 리셋]` 토글.
    - **시간 소진(`00:00:00`) 시 제약 규칙:** `업무 퀘스트` 게시판 열람은 가능하나 **`[퀘스트 등록]`, `[지원하기]`, `[결과물 제출]` 버튼이 즉시 비활성화(Disabled + 툴팁 안내)**됨. 단, **`효성마을` 중고거래는 남은 시간과 무관하게 100% 정상 이용 가능.**
  - **멀티 페르소나 실시간 전환 스위치 (시연용):** 새로고침 없이 클릭 즉시 현재 로그인 유저가 전환되며 모든 권한과 UI가 실시간 반영됨.
    - **유저 1 (기본):** `김효성 대리` (마포마을 / 재무팀 / **골드 티어 (Lv.12)** / 보유 포인트: **1,500 P** / 오늘 완료 건수: 0/2) — *주요 역할: 퀘스트 요청자 & 중고물품 구매자*
    - **유저 2:** `이퀘스트 사원` (창원마을 / 생산기술팀 / **실버 티어 (Lv.7)** / 보유 포인트: **300 P** / 오늘 완료 건수: 1/2) — *주요 역할: 퀘스트 지원·수행자 & 중고물품 판매자*
    - **유저 3:** `박마스터 과장` (반포마을 / AI혁신팀 / **마스터 티어 (Lv.28)** / 보유 포인트: **5,200 P** / 오늘 완료 건수: 2/2 - 한도 도달 상태) — *주요 역할: 랭킹 1위 & 일일 완료 한도(2건) 도달 테스트용*
  - **테마 토글 버튼:** 라이트 모드(기본) ↔ 다크 모드(사이버펑크 게이밍 무드).

### 3.2 게이미피케이션, 포인트 경제 & 시즌제 밸런스
- **보상 체계 (퀘스트 1건 완료 시):**
  - **기본 고정 보상:** **+100 P (포인트)** 및 **+100 EXP (경험치)** 지급.
  - **추가 현상금(Bounty):** 요청자가 퀘스트 등록 시 본인의 보유 포인트에서 추가 현상금(예: 0P ~ 1,000P)을 걸 수 있음.
    - **에스크로(선차감) 로직:** 현상금을 걸고 등록하는 즉시 요청자의 보유 포인트에서 해당 금액이 선차감됨. (`모집중` 상태에서 퀘스트 삭제 시 요청자에게 100% 환불)
- **일일 퀘스트 완료 제한 (하루 최대 2건):**
  - 한 유저가 작업자로서 **하루에 완료(승인)받을 수 있는 업무 퀘스트는 최대 2건**으로 제한됨. (오늘 완료 건수가 `2/2`인 유저는 추가 지원 불가 또는 완료 제한 안내 표시)
- **일일 퀘스트 (Daily Quests - 총 4종):**
  - 항목: ① 오늘 오피스퀘스트 접속하기, ② 업무 퀘스트 1회 등록하기, ③ 업무 퀘스트 1회 완료하기, ④ 지원한 퀘스트 채택되기 1회
  - 보상: 각 항목 달성 시 **+10 P 및 +50 EXP** 즉시 지급 (클레임 버튼 및 도트 코인 이펙트).
- **레벨업 및 6단계 티어 테이블 (시연 최적화를 위해 빠른 승급 밸런스 적용):**
  - **1 레벨업당 필요 EXP:** `100 EXP`
  - **티어 구간:**
    1. `브론즈 (Bronze)`: Lv. 1 ~ 4
    2. `실버 (Silver)`: Lv. 5 ~ 9
    3. `골드 (Gold)`: Lv. 10 ~ 14
    4. `플래티넘 (Platinum)`: Lv. 15 ~ 19
    5. `다이아 (Diamond)`: Lv. 20 ~ 24
    6. `마스터 (Master)`: Lv. 25 이상
- **시즌제 및 초기화 규칙:**
  - 대시보드에 `2026 Season 1 종료까지 D-14` 카운터와 `시즌 TOP 5 랭킹 보드` 표시.
  - **`[시즌 초기화 시뮬레이션]` 버튼 제공:** 클릭 시 모든 유저의 레벨이 `Lv.1 (브론즈, 0 EXP)`로 초기화되고 새 시즌 배지가 부여되지만, **기존에 획득한 '효성마을 거래용 보유 포인트(P)'는 100% 그대로 유지됨**을 시각적으로 증명.

### 3.3 메뉴 1: 업무 퀘스트 (Office Quest)
상단 `업무 퀘스트` 진입 시 좌측 사이드바 메뉴에 다음 3가지 탭이 존재합니다.

#### ① 좌측 메뉴 A: `일일 퀘스트`
- 오늘의 4대 일일 미션 카드 리스트, 달성 진행 바(Progress Bar), 보상 수령 버튼, 내 캐릭터 도트 스테이터스 표시.

#### ② 좌측 메뉴 B: `퀘스트 등록`
- **보안서약서 강제 모달 (Security Pledge Modal):**
  - 퀘스트 등록 폼 제출 시(그리고 지원자가 `[지원하기]` 클릭 시) **매번 예외 없이** 사내 보안서약서 모달이 팝업됨. ("대외비 및 기밀문서 업로드 금지, 개인정보 마스킹 준수 등" 체크박스 동의 후에만 실제 액션 진행)
- **입력 폼 구성:**
  - **분류 선택 (`문의` vs `요청`):**
    - `문의`: 일반 질문/노하우 요청. **일반 파일 업로드는 비활성화되며, 오직 '스크린샷 이미지 첨부'까지만 가능.**
    - `요청`: 엑셀 작업, PPT 디자인, 초안 작성 등 실무 대행. **사내 SharePoint 연동용 자료 파일 업로드 가능.**
  - **제목 및 추가 현상금(Bounty) 포인트 설정:** 내 보유 포인트 한도 내에서 추가 포인트 설정 슬라이더/입력창 제공.
  - **본문 에디터 (TinyMCE 5.10.2 Self-Hosted / Fallback):**
    - 로컬 스크립트 또는 클라우드 API 키 경고 배너가 절대 뜨지 않는 클린 설정의 **TinyMCE 5.10.2 스타일 풀 리치 텍스트 에디터**(표 삽입, 글자색, 정렬, 리스트, 코드블록, 이미지 삽입 툴바 완비)를 구현.
  - **첨부파일 Mock 업로드 (SharePoint 자동 변환):**
    - 로컬 파일을 선택하면 파일명과 용량을 추출하여 `https://hyosung.sharepoint.com/sites/officequest/Shared%20Documents/[파일명]` 형태의 **공식 SharePoint 보안 링크 배지**로 자동 변환하여 첨부.
  - 등록 완료 시: **1.8초 하이퍼 프레임 도트 모션 오버레이 모달** 재생 후 게시판으로 이동.

#### ③ 좌측 메뉴 C: `업무퀘스트` (게시판 & 상세 워크플로우)
- **게시판 리스트:**
  - 분류 필터(`전체`, `문의`, `요청`), 상태 필터(`모집중`, `진행중`, `완료`), 검색창 제공.
  - 각 행에 `[분류 배지]`, `[상태 배지(모집중/진행중/완료)]`, `제목`, `보상(기본 100P + 현상금 NP)`, `요청자(부서/티어 아이콘)`, `지원자 수`, `조회수(클릭 시 +1 증가)` 표시.
- **상세 화면 및 상태 전이 워크플로우 (핵심):**
  1. **`모집중` 상태:**
     - 요청자 본인에게는 `[수정]`, `[삭제]` 버튼 노출 (삭제 시 현상금 환불).
     - 타 유저(지원자)에게는 `[지원하기]` 버튼 노출 (클릭 시 **보안서약서 모달** 동의 후 한 줄 각오와 함께 지원 등록).
     - 요청자는 하단 **지원자 리스트**에서 지원자들의 티어/소속/각오를 확인하고 **딱 1명을 `[채택하기]`** 할 수 있음.
     - **주의:** 채택되기 전까지는 지원자들의 결과물 제출 에디터가 엄격히 비활성화(잠금)됨.
  2. **`진행중` 상태 (채택 완료 직후 자동 변경):**
     - `진행중` 또는 `완료` 상태가 되는 순간 **요청자의 게시글 `[수정]` 및 `[삭제]` 버튼은 즉시 잠김(불가)**.
     - 요청자와 채택된 작업자 간에 **`[💬 팀즈(Teams) 대화하기 - 업무 인수인계]`** 버튼 활성화.
     - **채택된 작업자 전용 영역 활성화:** 답변 작성용 리치 텍스트 에디터와 완료 파일 업로드(SharePoint 링크 변환) 폼이 열리며 `[결과물 제출하기]` 가능.
  3. **검수: `[퀘스트 완료(승인)]` 및 `[반려(재작업 요청)]`:**
     - 작업자가 결과물을 제출하면 요청자에게 2개의 버튼이 표시됨:
       - **`[🔄 반려 (보완 요청)]`:** 반려 사유를 입력하면 상태가 `진행중(보완요청)`으로 유지되며 작업자가 다시 수정 제출 가능.
       - **`[✅ 퀘스트 완료 (승인)]`:** 클릭 즉시 **1.8초 하이퍼 프레임 몬스터 처치 & 코인 획득 도트 모션 모달**이 터지며, 작업자에게 `기본 100P + 현상금 포인트`와 `100 EXP`가 즉시 지급되고 게시글 상태가 `완료`로 변경됨.

### 3.4 메뉴 2: 효성마을 (사내 포인트 중고거래 마켓)
- **좌측 사이드바 (사업장별 마을 게시판):**
  - 기본 선택 탭: **`전체 마을 모아보기`**
  - 개별 사업장 탭: `마포마을`, `회현마을`, `반포마을`, `수서마을`, `창원마을`, `울산마을` + 상단 `[+ 중고물품 글 등록]` 버튼.
- **물품 등록 및 수정 스펙:**
  - **마을 선택:** 마포 / 회현 / 반포 / 수서 / 창원 / 울산 중 택 1.
  - **제품 분류:** `디지털/가전`, `생활/주방`, `의류/잡화`, `도서/티켓/쿠폰`, `취미/기타`.
  - **거래 방식:** `포인트 판매`(가격 P 입력) 또는 `무료 나눔 (0 P)`.
  - **본문 작성:** 풀 리치 텍스트 에디터 + 상품 사진 다중 등록(샘플 프리셋 이미지 원클릭 추가 및 로컬 이미지 Base64 미리보기 지원).
- **마을 게시판 카드 & 상세 인터랙션:**
  - 각 게시글에 `[마을 배지]`, `[상태 배지: 거래가능 / 예약중 / 거래완료]`, `[분류]`, `가격(P 또는 무료나눔)`, `❤️ 좋아요(토글 및 카운트 증가)`, `조회수` 표시.
  - **`[💬 판매자와 팀즈 대화하기]`:** 클릭 시 우측 하단 가상 팀즈 채팅창 오픈.
- **중고거래 상태 제어 및 포인트 결제/이동 로직 (엄격 구현):**
  - **경로 A (구매자 주도 - `거래가능` 상태일 때):**
    - 구매자가 상세 페이지에서 **`[🛒 샀어요 (구매/나눔 요청)]`** 버튼 클릭.
    - **포인트 부족 예외 처리:** 구매자의 현재 보유 포인트가 상품 가격보다 적으면 *"보유 포인트가 부족합니다! 업무 퀘스트를 수행해 포인트를 모아보세요."* 경고 모달을 띄우고 진행 차단.
    - 포인트가 충분하면 판매자에게 `[구매 확인 요청]` 알림이 뜨고, 판매자가 **`[거래 승인]`**을 누르면 거래 성사!
  - **경로 B (판매자 주도 - 조직도 연동 예약자/구매자 지정):**
    - 판매자는 게시글 상태 변경 메뉴에서 **그룹웨어 조직도 모달**을 열어 특정 직원을 **'예약자(`예약중`)'** 또는 **'최종 구매자(`거래완료`)'**로 지정할 수 있음.
    - **핵심 제약 (`예약중` 상태 규칙):** 판매자가 특정 사용자를 지정하여 게시글을 **`예약중`**으로 변경한 경우, **지정된 예약자 본인 외의 다른 모든 직원에게는 `[샀어요]` 버튼이 비활성화(`예약중인 상품입니다 - 지정 예약자 외 구매 불가`)**되며, 오직 지정된 사용자만 `[샀어요]`를 누를 수 있음!
  - **포인트 정산:** 거래가 최종 완료(`거래완료`)되는 순간, 구매자의 포인트에서 상품 가격만큼 차감되고 판매자의 포인트로 즉시 이동(무료 나눔 0P의 경우 0P 이동 기록)되며 양측 거래 내역에 기록됨.
